================================================================================
   คู่มือวิธีเปิดใช้งานโปรแกรม: 160 ธีระ สายซิ่ง (160 Teera Sai Sing)
   ศูนย์รวมรถจักรยานยนต์ไม่เกิน 160 cc
================================================================================

1. วิธีเปิดโปรเจกต์ใน VS Code
--------------------------------------------------------------------------------
   วิธีที่ 1 (ผ่านเมนู VS Code):
   - เปิดโปรแกรม Visual Studio Code
   - ไปที่แถบเมนูด้านบนเลือก File -> Open Folder...
   - เลือกโฟลเดอร์: C:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web
   - กดปุ่ม "Select Folder"

   วิธีที่ 2 (ผ่าน Command Prompt / PowerShell):
   - เปิด PowerShell แล้วพิมพ์คำสั่ง:
     cd "C:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web"
     code .


2. วิธีติดตั้งไลบรารี (Dependencies)
--------------------------------------------------------------------------------
   ก่อนรันครั้งแรก ตรวจสอบว่าได้ติดตั้งไลบรารีครบถ้วน โดยพิมพ์คำสั่งใน Terminal:
   python -m pip install -r requirements.txt

   (ไลบรารีหลักที่ใช้: Flask, reportlab, Pillow, Werkzeug, Jinja2)


3. วิธีเปิด Terminal ที่โฟลเดอร์โปรเจกต์ใน VS Code
--------------------------------------------------------------------------------
   - กดปุ่มลัด: Ctrl + ` (ปุ่มตัวหนอน) หรือไปที่เมนูด้านบน Terminal -> New Terminal
   - ตรวจสอบว่า Path ที่แสดงอยู่ที่:
     C:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web
   - หากยังไม่อยู่ ให้พิมพ์คำสั่ง:
     cd "C:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web"


4. คำสั่งรันเว็บไซต์ (Start Server)
--------------------------------------------------------------------------------
   พิมพ์คำสั่งใน Terminal:
   python app.py

   เมื่อรันสำเร็จจะปรากฏข้อความบนหน้าจอ:
   ==================================================
      160 ธีระ สายซิ่ง (160 TEERA SAI SING) FLASK   
      ศูนย์รวมรถจักรยานยนต์ความจุไม่เกิน 160 cc     
   ==================================================
    * Running on http://127.0.0.1:5000


5. URL สำหรับเปิดเว็บไซต์ในเบราว์เซอร์
--------------------------------------------------------------------------------
   เปิด Google Chrome, Microsoft Edge หรือ Firefox แล้วเข้าที่ลิงก์:
   http://127.0.0.1:5000

   ข้อมูลบัญชีสำหรับทดสอบและนำเสนออาจารย์:
   - บัญชี Admin (ผู้ดูแลระบบ):
     อีเมล: admin@bikeshop.com
     รหัสผ่าน: admin1234
   - บัญชี Customer (ลูกค้าตัวอย่าง):
     อีเมล: customer@test.com
     รหัสผ่าน: customer1234


6. วิธีหยุดเซิร์ฟเวอร์ (Stop Server)
--------------------------------------------------------------------------------
   - คลิกที่หน้าต่าง Terminal ที่กำลังรันอยู่
   - กดปุ่มคีย์บอร์ด: Ctrl + C
   - เซิร์ฟเวอร์จะหยุดการทำงานทันที


7. วิธีแก้ปัญหาเบื้องต้นเมื่อรันไม่ได้ (Troubleshooting)
--------------------------------------------------------------------------------
   ปัญหาที่ 1: "python : The term 'python' is not recognized"
   -> สาเหตุ: ยังไม่ได้ตั้งค่า Environment Variable สำหรับ Python หรือพิมพ์คำสั่งผิด (เช่น pyhon)
   -> วิธีแก้: ตรวจสอบการสะกด "python" หรือใช้ตัวเรียกผ่าน Python Launcher: py app.py

   ปัญหาที่ 2: "can't open file '...app.py': [Errno 2] No such file or directory"
   -> สาเหตุ: Terminal อยู่ผิดโฟลเดอร์ เช่น อยู่ที่ C:\Users\User แทนที่จะเป็นโฟลเดอร์โปรเจกต์
   -> วิธีแก้: พิมพ์ cd "C:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web" ก่อนสั่ง python app.py

   ปัญหาที่ 3: "Port 5000 is already in use" (พอร์ตชนกัน)
   -> วิธีแก้: มี Flask รันค้างอยู่ ให้กด Ctrl + C ใน Terminal เก่า หรือสั่งปิด Task python.exe ใน Task Manager
