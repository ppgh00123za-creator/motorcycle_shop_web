โครงสร้างโปรเจกต์ "160 ธีระ สายซิ่ง" (motorcycle_shop_web) แบบเรียบง่าย (Minimal Standard)
========================================================================================

โปรเจกต์นี้ได้รับการจัดระเบียบให้มีโฟลเดอร์หลักน้อยที่สุดเท่าที่ระบบ Flask ทำงานได้อย่างสมบูรณ์
โดยเหลือเพียง 4 โฟลเดอร์มาตรฐานหลัก ดังนี้:

1. โครงสร้างโฟลเดอร์หลัก (Main Directories):
----------------------------------------------------------------------------------------
/motorcycle_shop_web
│
├── instance/                   # จัดเก็บฐานข้อมูล SQLite จริงของระบบ
│   └── motorcycle_shop.db      # ฐานข้อมูล (users, products, orders, payments, receipts, archived_orders)
│
├── routes/                     # รวบรวมโมดูลตรรกะระบบและเครื่องมือช่วยเหลือ (Routing & Logic)
│   ├── __init__.py             # ประกาศแพ็กเกจ routes
│   ├── auth.py                 # ระบบยืนยันตัวตน เข้าสู่ระบบ สมัครสมาชิก ตรวจสอบรหัสผ่านปลอดภัย
│   ├── shop.py                 # แค็ตตาล็อก กรองยี่ห้อ สเปกรถ ตะกร้าสินค้า
│   ├── customer.py             # สั่งซื้อ (Checkout), แนบสลิป, ประวัติคำสั่งซื้อ, ดาวน์โหลดใบเสร็จ PDF
│   ├── admin.py                # แดชบอร์ดสรุปผล, จัดการสต็อกสินค้า, อนุมัติสลิป, รายงานยอดขาย
│   ├── receipt.py              # ตัวสร้างใบเสร็จรับเงิน PDF ด้วย ReportLab (รวมมาจาก utils)
│   └── helpers.py              # ฟังก์ชันตรวจสอบความถูกต้องของไฟล์อัปโหลด (รวมมาจาก utils)
│
├── static/                     # ทรัพยากรไฟล์สถิตและมีเดียทั้งหมดของเว็บไซต์ (Static Assets)
│   ├── css/style.css           # สไตล์ชีตหลัก Dark Cinematic / Red White สไตล์ 160 ธีระ สายซิ่ง
│   ├── fonts/                  # ฟอนต์ภาษาไทย (tahoma.ttf, tahomabd.ttf) สำหรับพิมพ์ใบเสร็จ PDF
│   ├── images/                 # ไฟล์ภาพเวกเตอร์ SVG สำรอง และ Placeholder
│   ├── รูปภาพ/                 # ศูนย์รวมภาพถ่ายต้นฉบับจริง (รถ 20 รุ่น, แบนเนอร์, โลโก้, ภาพพื้นหลัง)
│   └── ไฟล์ที่ผู้ใช้อัปโหลด/      # ไฟล์ที่อัปโหลดผ่านเว็บ (slips/ สลิปโอนเงิน และ products/ ภาพสินค้า)
│
├── templates/                  # แม่แบบหน้าจอ HTML (Jinja2 Templates)
│   ├── base.html               # โครงร่างหลัก Navbar, Footer, Background
│   ├── index.html              # หน้าแรกแสดงอัตลักษณ์ร้าน แบนเนอร์ สินค้าแนะนำ
│   ├── products.html           # แค็ตตาล็อกสินค้าและระบบกรองสเปก
│   ├── product_detail.html     # รายละเอียดสเปกเจาะลึก 5 หมวดหลักของรถทั้ง 20 รุ่น
│   ├── cart.html               # หน้าตะกร้าสินค้า
│   ├── checkout.html           # ฟอร์มยืนยันคำสั่งซื้อ
│   ├── orders.html             # ประวัติคำสั่งซื้อ (แสดง 3 ออเดอร์ล่าสุดที่เสร็จสิ้น และออเดอร์ที่รอดำเนินการ)
│   ├── order_detail.html       # รายละเอียดออเดอร์ แนบสลิป ไทม์ไลน์สถานะ
│   ├── login.html              # หน้าเข้าสู่ระบบ พร้อมปุ่มดูรหัสผ่าน
│   ├── register.html           # หน้าสมัครสมาชิก พร้อมปุ่มดูรหัสผ่าน
│   └── admin/                  # แม่แบบสำหรับระบบจัดการหลังบ้านของผู้ดูแลระบบ
│       ├── nav.html            # แถบเมนูนำทางหลังบ้าน
│       ├── dashboard.html      # แดชบอร์ดสถิติ ยอดขาย ออเดอร์ สต็อก
│       ├── products.html       # ตารางจัดการสินค้าหลังบ้าน
│       ├── product_form.html   # แบบฟอร์มเพิ่ม/แก้ไขข้อมูลรถ
│       ├── orders.html         # ตารางคำสั่งซื้อทั้งหมด และแท็บคลังประวัติ (Archived)
│       ├── order_detail.html   # จัดการคำสั่งซื้อและเปลี่ยนสถานะ
│       ├── payments.html       # ตรวจสอบสลิป อนุมัติ/ปฏิเสธยอดเงิน
│       └── reports.html        # รายงานสรุปยอดขายและสต็อก
│
├── app.py                      # จุดเริ่มต้นของแอปพลิเคชัน Flask กำหนดค่า Route ส่วนกลาง และ Jinja Filters
├── config.py                   # การกำหนดค่าตัวตนร้านค้า (160 ธีระ สายซิ่ง) และแมปปิ้งรูปภาพสินค้า
├── database.py                 # ระบบฐานข้อมูล SQLite (Schema, Migration, ฟังก์ชันจัดการ Order Archive)
├── specs_data.py               # ข้อมูลสเปกทางเทคนิคอย่างละเอียด 5 หมวดหลักครบ 20 รุ่น พร้อมแหล่งอ้างอิง
├── test_app.py                 # ชุดทดสอบอัตโนมัติ (Automated Test Suite ครอบคลุม 10 หัวข้อหลัก)
├── requirements.txt            # รายการไลบรารีที่จำเป็น (Flask, ReportLab, Werkzeug ฯลฯ)
├── คำอธิบายโครงสร้าง.txt         # ไฟล์เอกสารสรุปโครงสร้างนี้ (ไฟล์เดียวที่โฟลเดอร์หลัก)
├── รายการไฟล์.txt                 # สรุปรายชื่อไฟล์ในโปรเจกต์
├── วิธีเปิดโปรแกรม.txt           # คู่มือขั้นตอนการเปิดใช้งาน
├── อธิบายโค้ด.txt               # สรุปการทำงานของโค้ดสำหรับตอบอาจารย์
├── README.md                   # คู่มือโปรเจกต์
└── PRESENTATION_GUIDE.md       # สคริปต์ขั้นตอนการนำเสนอ
========================================================================================
