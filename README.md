# MOTO 160 BIKE SHOP - เว็บไซต์ร้านขายรถจักรยานยนต์ไม่เกิน 160 cc

ระบบร้านค้าออนไลน์จำหน่ายรถจักรยานยนต์ความจุเครื่องยนต์ไม่เกิน 160 cc พัฒนาด้วย **Python (Flask)**, **SQLite**, **HTML5/CSS3** และ **ReportLab** เหมาะสำหรับโปรเจกต์นักศึกษามหาวิทยาลัยปี 2 ที่กำลังเรียนวิชาเขียนโปรแกรม Python

---

## 1. จุดเด่นของระบบ

- **เชื่อมต่อจริงครบวงจร:** Backend (Flask), Database (SQLite), และ Frontend (Jinja2 Templates) เชื่อมต่อกันจริง
- **พิกัดรถไม่เกิน 160 cc:** มีข้อมูลรถตัวอย่าง 20 รุ่น (รถครอบครัว, ออโตเมติก, สปอร์ต/มินิ) และมีระบบป้องกันไม่ให้บันทึกรถเกิน 160 cc
- **ตะกร้าและการสั่งซื้อแบบ Transaction:** ตัดสต็อกสินค้าในฐานข้อมูลทันทีเมื่อสั่งซื้อ ป้องกันการขายเกินจำนวน และคืนสต็อกอัตโนมัติเมื่อยกเลิก
- **ระบบแนบสลิปและตรวจสอบ:** ลูกค้าอัปโหลดสลิปโอนเงินได้จริง ผู้ดูแลระบบ (Admin) ตรวจสอบและกดอนุมัติ/ปฏิเสธได้
- **ใบเสร็จรับเงิน PDF:** สร้างใบเสร็จ PDF ด้วย ReportLab รองรับภาษาไทยสมบูรณ์แบบ (ดาวน์โหลดได้เฉพาะคำสั่งซื้อที่ได้รับการอนุมัติแล้ว)
- **ระบบความปลอดภัย:** เก็บรหัสผ่านด้วย Password Hash (Werkzeug), ตรวจสอบสิทธิ์ฝั่ง Server ทุก Route, และใช้ SQL Parameterized Queries ป้องกัน SQL Injection

## 4. ขั้นตอนการติดตั้งและเปิดใช้งาน

### ขั้นตอนที่ 1: เข้าสู่โฟลเดอร์โปรเจกต์
เปิด PowerShell หรือ Command Prompt:
```powershell
cd c:\Users\User\Desktop\ร้านขายเวฟ\motorcycle_shop_web
```

### ขั้นตอนที่ 2: ติดตั้ง Dependencies
```powershell
python -m pip install -r requirements.txt
```

### ขั้นตอนที่ 3: สั่งรันแอปพลิเคชัน
```powershell
python app.py
```

## 6. การทดสอบระบบอัตโนมัติ (Automated Testing)

สามารถรันชุดทดสอบเพื่อพิสูจน์การทำงานของระบบทุกส่วนได้ด้วยคำสั่ง:
```powershell
python test_app.py
```
ชุดทดสอบจะทำการทดสอบอัตโนมัติ:
1. การเปิดหน้าแรกและดึงข้อมูลจาก SQLite
2. การค้นหาและกรองรถมอเตอร์ไซค์
3. ตรวจสอบเงื่อนไขความจุเครื่องยนต์ไม่เกิน 160 cc
4. การทำงานของระบบสมัครสมาชิกและการเข้ารหัส Hash รหัสผ่าน
5. กระบวนการสั่งซื้อ ตัดสต็อก แนบสลิป อนุมัติ และดาวน์โหลด PDF
6. การป้องกันการเพิ่มรถเกิน 160 cc
7. การยกเลิกคำสั่งซื้อแล้วคืนสต็อกเข้าฐานข้อมูล
