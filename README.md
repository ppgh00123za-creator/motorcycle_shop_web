# 160 ธีระ สายซิ่ง - เว็บไซต์ร้านขายรถจักรยานยนต์ (ไม่เกิน 160 cc)

เว็บแอปพลิเคชันร้านค้าออนไลน์จำหน่ายรถจักรยานยนต์ขนาดเครื่องยนต์ไม่เกิน 160 cc พัฒนาด้วยภาษา **Python (Flask)** ร่วมกับฐานข้อมูล **SQLite** หน้าเว็บออกแบบด้วย **HTML5 / CSS3 / JavaScript** และมีระบบออกใบเสร็จรับเงิน PDF ด้วย **ReportLab**

---

## 1. ฟังก์ชันการทำงานของระบบ

- **หน้าบ้าน (สำหรับลูกค้า):**
  - ค้นหาและกรองรถมอเตอร์ไซค์ตามหมวดหมู่ (รถครอบครัว, รถออโตเมติก, รถสปอร์ต/มินิไบค์) และช่วงราคา
  - ดูรายละเอียดสเปกตัวรถ (cc, ระบบเกียร์, ความจุถังน้ำมัน, ระบบเบรก)
  - ระบบตะกร้าสินค้า ปรับจำนวนสินค้า และคำนวณราคารวม
  - ยืนยันการสั่งซื้อ กรอกที่อยู่จัดส่ง และตัดสต็อกสินค้าในระบบทันที
  - แนบรูปสลิปโอนเงินเพื่อแจ้งชำระเงิน
  - ติดตามสถานะคำสั่งซื้อ และดาวน์โหลดใบเสร็จรับเงิน (PDF) หลังจากแอดมินอนุมัติ

- **หลังบ้าน (สำหรับผู้ดูแลระบบ / Admin):**
  - แดชบอร์ดสรุปยอดขาย รายการคำสั่งซื้อ และแจ้งเตือนรถที่สต็อกใกล้หมด
  - ตรวจสอบรูปสลิปโอนเงินของลูกค้า และกดอนุมัติหรือปฏิเสธคำสั่งซื้อ
  - จัดการรายการรถ (เพิ่ม / แก้ไข / ปรับสต็อก) โดยระบบจะล็อกไม่ให้บันทึกรถที่มีขนาดเกิน 160 cc
  - ดูประวัติการปรับสต็อกย้อนหลัง และรายงานยอดขาย

- **ความปลอดภัยและเอกสาร:**
  - รหัสผ่านของผู้ใช้ถูกเข้ารหัสด้วย Password Hash ก่อนบันทึกลงฐานข้อมูล
  - มีระบบตรวจสอบสิทธิ์ แยกหน้าของลูกค้าทั่วไปกับแอดมินออกจากกัน
  - ใบเสร็จรับเงิน PDF จัดรูปแบบภาษาไทย สระและวรรณยุกต์ไม่ลอย

## 2. โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้ฐานข้อมูล **SQLite** (`instance/motorcycle_shop.db`) โดยมีตารางที่เชื่อมโยงกันดังนี้:

- **`users`** : เก็บข้อมูลผู้ใช้งาน (ชื่อ, อีเมล, รหัสผ่าน Hash, เบอร์โทร, ที่อยู่, บทบาท `customer` หรือ `admin`)
- **`products`** : เก็บข้อมูลรถมอเตอร์ไซค์ (รหัสสินค้า, ยี่ห้อ, รุ่น, ปี, `engine_cc` กำหนดไว้ $\le$ 160, ราคา, จำนวนสต็อก, หมวดหมู่, รูปภาพ)
- **`orders`** : ข้อมูลคำสั่งซื้อ (เลขออเดอร์, ข้อมูลผู้สั่ง, ยอดรวม, สถานะ เช่น รอชำระเงิน / รอตรวจสอบ / ชำระเงินเรียบร้อย / ยกเลิก)
- **`order_items`** : รายการสินค้าที่อยู่ในแต่ละออเดอร์ (รหัสสินค้า, ชื่อรุ่น, ราคาต่อหน่วย, จำนวน, ยอดรวม)
- **`payments`** : ข้อมูลการแจ้งชำระเงิน (เลขออเดอร์, ไฟล์รูปสลิป, ยอดเงินที่โอน, สถานะการตรวจสอบ, ผู้ตรวจ)
- **`receipts`** : ข้อมูลการออกใบเสร็จรับเงิน (เลขที่ใบเสร็จ, รหัสคำสั่งซื้อ, วันที่ออกใบเสร็จ)
- **`order_status_history`** : บันทึกไทม์ไลน์ทุกครั้งที่มีการเปลี่ยนสถานะของออเดอร์
- **`stock_adjustments`** : บันทึกประวัติการปรับสต็อกรถของแอดมิน (จำนวนก่อนแก้, จำนวนหลังแก้, เหตุผล)
- **`support_tickets`** : เก็บข้อความติดต่อสอบถามหรือแจ้งปัญหาจากลูกค้า

## 3. โครงสร้างโฟลเดอร์โปรเจกต์

```text
motorcycle_shop_web/
├── app.py                     # ไฟล์หลักสำหรับรัน Flask Application และจัดการเส้นทาง URL
├── config.py                  # ข้อมูลการตั้งค่าระบบและรายละเอียดร้านค้า
├── database.py                # ระบบเชื่อมต่อฐานข้อมูล SQLite สร้างตาราง และใส่ข้อมูลตั้งต้น
├── specs_data.py              # ข้อมูลสเปกทางเทคนิคของรถแต่ละรุ่น
├── requirements.txt           # รายชื่อไลบรารี Python ที่ต้องติดตั้ง
├── README.md                  # เอกสารอธิบายระบบและคู่มือการใช้งาน
├── instance/
│   └── motorcycle_shop.db     # ไฟล์ฐานข้อมูล SQLite พร้อมข้อมูลตัวอย่าง
├── routes/
│   ├── __init__.py
│   ├── admin.py               # หน้าแดชบอร์ด, จัดการสินค้า, ตรวจสลิป, สรุปยอดขาย
│   ├── auth.py                # ระบบล็อกอิน, สมัครสมาชิก, ออกจากระบบ, ลืมรหัสผ่าน
│   ├── customer.py            # สั่งซื้อสินค้า, แนบสลิป, ประวัติออเดอร์, แจ้งปัญหา
│   ├── helpers.py             # ฟังก์ชันช่วยจัดฟอร์แมตเงิน วันที่ และเช็กสิทธิ์
│   ├── receipt.py             # ฟังก์ชันสร้างใบเสร็จรับเงิน PDF (ReportLab)
│   └── shop.py                # หน้าร้าน, ค้นหารถ, รายละเอียดสินค้า, ตะกร้า
├── templates/
│   ├── base.html              # ไฟล์เทมเพลตหลัก (Navbar + Footer)
│   ├── home.html              # หน้าแรก มีแบนเนอร์และรถรุ่นแนะนำ
│   ├── products.html          # หน้ารวมรถทั้งหมด พร้อมตัวกรองค้นหา
│   ├── product_detail.html    # หน้ารายละเอียดรถ สเปก และปุ่มสั่งซื้อ
│   ├── cart.html              # หน้าตะกร้าสินค้า
│   ├── checkout.html          # หน้ากรอกที่อยู่และยืนยันการสั่งซื้อ
│   ├── orders.html            # หน้าประวัติการสั่งซื้อของลูกค้า
│   ├── order_detail.html      # หน้ารายละเอียดออเดอร์ แนบสลิป และโหลด PDF
│   ├── login.html             # หน้าล็อกอิน
│   ├── register.html          # หน้าสมัครสมาชิก
│   └── admin/
│       ├── dashboard.html     # แดชบอร์ดสรุปภาพรวม
│       ├── products.html      # จัดการรายการรถและสต็อก
│       ├── product_form.html  # ฟอร์มเพิ่ม/แก้ไขข้อมูลรถ
│       ├── orders.html        # รายการคำสั่งซื้อทั้งหมด
│       ├── order_detail.html  # รายละเอียดออเดอร์ฝั่งแอดมิน
│       ├── payments.html      # หน้าเปิดดูรูปสลิปและกดยืนยันยอดเงิน
│       └── reports.html       # หน้าสรุปรายงานยอดขาย
└── static/
    ├── css/
    │   └── style.css          # ไฟล์ตกแต่งหน้าเว็บ
    ├── fonts/                 # ฟอนต์ภาษาไทยสำหรับหน้าเว็บและไฟล์ PDF
    ├── images/                # รูปภาพตกแต่งและไอคอน
    └── รูปภาพ/                # รูปภาพรถมอเตอร์ไซค์แต่ละรุ่น
```

## 4. วิธีติดตั้งและเปิดใช้งาน

### 1. เข้าไปที่โฟลเดอร์โปรเจกต์
```bash
cd motorcycle_shop_web
```

### 2. ติดตั้งไลบรารีที่จำเป็น
```bash
pip install -r requirements.txt
```

### 3. เริ่มรันเซิร์ฟเวอร์
```bash
python app.py
```

### 4. เปิดใช้งานผ่านเบราว์เซอร์
เปิดเบราว์เซอร์แล้วพิมพ์ URL:
```text
http://127.0.0.1:5000
```
