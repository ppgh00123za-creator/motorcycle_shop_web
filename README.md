# 160 ธีระ สายซิ่ง - เว็บไซต์ร้านขายรถจักรยานยนต์ความจุไม่เกิน 160 cc

ระบบร้านค้าออนไลน์จำหน่ายรถจักรยานยนต์ความจุเครื่องยนต์ไม่เกิน 160 cc พัฒนาด้วยภาษา **Python (Flask)** ร่วมกับฐานข้อมูล **SQLite**, ออกแบบหน้าเว็บด้วย **HTML5 / CSS3 / JavaScript** และรองรับการออกเอกสารใบเสร็จรับเงิน PDF ภาษาไทยด้วย **ReportLab**

---

## 1. จุดเด่นและการทำงานของระบบ

- **ระบบสถาปัตยกรรม Full-Stack:** เชื่อมต่อการทำงานจริงระหว่าง Backend (Flask), Database (SQLite) และ Frontend (Jinja2 Templates) ครบทุกฟังก์ชัน
- **จำกัดพิกัดความจุไม่เกิน 160 cc:** มีระบบตรวจสอบความถูกต้อง (Validation) ทั้งฝั่งหน้าบ้านและหลังบ้าน ป้องกันไม่ให้มีการเพิ่มหรือแก้ไขรถที่มีขนาดความจุเกิน 160 cc
- **ระบบตะกร้าและสั่งซื้อแบบ Transaction:** ตัดสต็อกสินค้าในฐานข้อมูลทันทีเมื่อทำการสั่งซื้อ ป้องกันการสั่งซื้อเกินสต็อกที่มีอยู่จริง พร้อมระบบคืนสต็อกอัตโนมัติหากยกเลิกคำสั่งซื้อ
- **ระบบแนบสลิปและตรวจสอบการชำระเงิน:** ลูกค้าสามารถอัปโหลดไฟล์ภาพสลิปโอนเงินได้จริง ผู้ดูแลระบบ (Admin) มีหน้าต่างตรวจสอบสลิปและสามารถกดอนุมัติหรือปฏิเสธคำสั่งซื้อได้
- **ระบบออกใบเสร็จรับเงิน PDF:** สร้างเอกสารใบเสร็จรับเงินอิเล็กทรอนิกส์ด้วย ReportLab จัดรูปแบบตารางสวยงาม พร้อมรองรับฟอนต์ภาษาไทยสมบูรณ์แบบ
- **ระบบความปลอดภัย (Security):** จัดเก็บรหัสผ่านด้วยการเข้ารหัส Password Hash (Werkzeug Security), ป้องกัน SQL Injection ด้วย Parameterized Queries และมีระบบ Session Role-based Guard ตรวจสอบสิทธิ์ผู้ใช้งานทุกเส้นทาง (Routes)

## 2. โครงสร้างโฟลเดอร์โปรเจกต์

```text

├── requirements.txt           # รายการแพ็กเกจไลบรารีภายนอกที่จำเป็น
├── README.md                  # เอกสารแนะนำและคู่มือการใช้งานโปรเจกต์

├── routes/
│   ├── __init__.py            # ไฟล์ระบุความเป็น Python Package
│   ├── admin.py               # เส้นทางระบบหลังบ้าน (Dashboard, CRUD สินค้า, ตรวจสลิป, รายงานสรุป)
│   ├── auth.py                # เส้นทางระบบผู้ใช้ (เข้าสู่ระบบ, สมัครสมาชิก, ออกจากระบบ, รีเซ็ตรหัสผ่าน)

│   └── shop.py                # เส้นทางหน้าร้าน (หน้าแรก, ค้นหา/กรองสินค้า, หน้ารายละเอียด, ตะกร้า)
├── templates/
│   ├── base.html              # Layout แม่แบบหลัก มี Navbar, แจ้งเตือน Flash Alert และ Footer
│   ├── home.html              # หน้าแรก (Hero Banner, หมวดหมู่รถ, รถรุ่นแนะนำ)
│   ├── products.html          # แค็ตตาล็อกรายการรถทั้งหมด พร้อมระบบค้นหาและตัวกรองราคา/หมวดหมู่
```

## 3. ความต้องการของระบบ (Prerequisites)

- **Python 3.10 ขึ้นไป**
- เว็บบราวเซอร์ เช่น Google Chrome, Microsoft Edge, Firefox, Safari

---

## 4. ขั้นตอนการติดตั้งและรันระบบ

### 1. เข้าสู่โฟลเดอร์โปรเจกต์
เปิด Terminal / PowerShell / Command Prompt แล้วเข้าไปที่โฟลเดอร์โปรเจกต์:
```bash
cd motorcycle_shop_web
```

### 2. ติดตั้ง Dependencies
ติดตั้งแพ็กเกจที่จำเป็นตามรายการใน `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. รันแอปพลิเคชัน Flask
สั่งเริ่มการทำงานของเซิร์ฟเวอร์:
```bash
python app.py
```

เมื่อระบบเริ่มทำงานเรียบร้อย จะแสดงข้อความในคอนโซล:
```text
==================================================
   160 ธีระ สายซิ่ง (160 TEERA SAI SING) FLASK   
   ศูนย์รวมรถจักรยานยนต์ความจุไม่เกิน 160 cc     
==================================================
 • เปิดเว็บไซต์ที่: http://127.0.0.1:5000
 • บัญชีผู้ดูแลระบบ (Admin): admin@bikeshop.com | รหัส: admin1234
 • บัญชีลูกค้าทดสอบ (Customer): customer@test.com | รหัส: customer1234
 • เวลาทำการ: วันพุธ 09:00 - 18:00 น.
==================================================
```

### 4. เปิดใช้งานผ่านเว็บเบราว์เซอร์
เปิดเบราว์เซอร์แล้วเข้าไปที่: **`http://127.0.0.1:5000`**

## 5. ข้อมูลบัญชีผู้ใช้สำหรับทดสอบระบบ (Test Accounts)

| บทบาท (Role) | อีเมล (Email) | รหัสผ่าน (Password) | สิทธิ์การใช้งานหลัก |
| :--- | :--- | :--- | :--- |
| **ผู้ดูแลระบบ (Admin)** | `admin@bikeshop.com` | `admin1234` | ดูแดชบอร์ด, จัดการสินค้า (CRUD), ปรับสต็อก, ตรวจสอบสลิปและอนุมัติการชำระเงิน, ดูรายงานยอดขาย |
| **ลูกค้าทดสอบ (Customer)** | `customer@test.com` | `customer1234` | เลือกชมรถ, เพิ่มลงตะกร้า, สั่งซื้อสินค้า, แนบสลิปชำระเงิน, ติดตามสถานะ, ดาวน์โหลดใบเสร็จรับเงิน PDF |

## 6. หมวดหมู่และรายการรถจักรยานยนต์ในระบบ (ความจุ $\le$ 160 cc)

ระบบมีข้อมูลรถจักรยานยนต์ตัวอย่างพร้อมจำหน่าย จัดแบ่งออกเป็น 3 หมวดหมู่หลัก:

1. **รถครอบครัว (Family Bikes):**
   - Honda Wave 110i (109 cc)
   - Honda Wave 125i (124 cc)
   - Honda Super Cub 110 (109 cc)
   - Honda Dream 100 (97 cc)
   - Yamaha Finn (114 cc)

2. **รถออโตเมติก (Automatic / Scooter):**
   - Honda Scoopy (109 cc)
   - Honda Click 125i (124 cc)
   - Honda Click 150i (149 cc)
   - Honda Click 160 (156 cc)
   - Honda PCX 150 (149 cc)
   - Honda PCX 160 (156 cc)
   - Honda Lead 125 (124 cc)
   - Yamaha Grand Filano (124 cc)
   - Yamaha Aerox 155 (155 cc)
   - Yamaha NMAX 155 (155 cc)
   - Yamaha Fino 115 (113 cc)

3. **รถสปอร์ตและมินิไบค์ (Sport & Mini Bikes):**
   - Honda MSX 125 (124 cc)
   - Honda CBR150R (149 cc)
   - Yamaha R15 (155 cc)
   - Suzuki Raider R150 (147 cc)
