   สำหรับเปิดดูและค้นหาโค้ดระหว่างสาธิตการทำงาน (Quick File Reference)

[โฟลเดอร์หลัก: motorcycle_shop_web]
│
├── [เอกสารประกอบการนำเสนอภาษาไทย]
│   ├── วิธีเปิดโปรแกรม.txt       <- คู่มือขั้นตอนเปิด VS Code และคำสั่งรันเซิร์ฟเวอร์
│   ├── อธิบายโค้ด.txt           <- คำอธิบายการทำงานของระบบสำหรับตอบอาจารย์
│   ├── คำอธิบายโครงสร้าง.txt     <- คำอธิบายบทบาทและโครงสร้างระบบที่โฟลเดอร์หลัก
│   ├── รายการไฟล์.txt           <- สรุปรายชื่อไฟล์และตำแหน่ง (ไฟล์นี้)
│   ├── README.md               <- เอกสารคู่มือโปรเจกต์แบบ Markdown
│   └── PRESENTATION_GUIDE.md   <- แผนการนำเสนอแบบลำดับการคลิกสาธิต
│
├── [ไฟล์แกนหลักของระบบ - Root Files]
│   ├── app.py                  <- จุดเริ่มต้น Flask Server, การตั้งค่า Config, การลงทะเบียน Blueprints
│   ├── config.py               <- การกำหนดค่าข้อมูลร้านค้า และการแมปปิ้งรูปภาพ
│   ├── database.py             <- โค้ดสร้างตาราง SQLite, Seed ข้อมูล 20 รุ่น, และฟังก์ชัน Order Archive
│   ├── specs_data.py           <- ข้อมูลสเปกทางเทคนิคอย่างละเอียด 5 หมวดหลักครบ 20 รุ่น
│   ├── requirements.txt        <- รายการไลบรารีที่จำเป็น (Flask, ReportLab, Werkzeug ฯลฯ)
│   └── test_app.py             <- ชุดทดสอบระบบอัตโนมัติ 10 รายการ (Automated Test Suite)
│
├── [1. โฟลเดอร์ฐานข้อมูล - instance]
│   └── instance/motorcycle_shop.db <- ไฟล์ฐานข้อมูล SQLite จริง เก็บข้อมูลทั้งหมด
│
├── [2. โฟลเดอร์ควบคุมระบบและโมดูลตรรกะ - routes]
│   ├── routes/__init__.py      <- ประกาศแพ็กเกจ routes
│   ├── routes/auth.py          <- ระบบสมาชิก: เข้าสู่ระบบ, สมัครสมาชิก, Hash รหัสผ่าน, สิทธิ์แอดมิน
│   ├── routes/shop.py          <- หน้าร้าน: หน้าแรก, ค้นหา/กรองสินค้า, หน้ารายละเอียด, ตะกร้าสินค้า
│   ├── routes/customer.py      <- ลูกค้า: สั่งซื้อ Transaction, แนบสลิป, ประวัติคำสั่งซื้อ, โหลดใบเสร็จ PDF
│   ├── routes/admin.py         <- ผู้ดูแล: แดชบอร์ด, จัดการสินค้า CRUD, ตรวจสลิป, รายงานยอดขาย
│   ├── routes/receipt.py       <- สร้างใบเสร็จรับเงิน PDF ภาษาไทยด้วย ReportLab (รวมมาจาก utils)
│   └── routes/helpers.py       <- ฟังก์ชันส่วนกลาง เช่น allowed_file() (รวมมาจาก utils)
│
├── [3. โฟลเดอร์หน้าเว็บ HTML - templates]
│   ├── templates/base.html          <- แม่แบบหลัก (Navbar, Flash alerts, Footer)
│   ├── templates/macros.html        <- คอมโพเนนต์ Reusable (การ์ดสินค้า, ป้ายสถานะ)
│   ├── templates/index.html         <- หน้าแรก (แบนเนอร์, หมวดหมู่, รถแนะนำ)
│   ├── templates/products.html      <- หน้ารวมรถทั้งหมด พร้อมตัวกรองค้นหา
│   ├── templates/product_detail.html<- หน้ารายละเอียดรถ และปุ่มสั่งซื้อ
│   ├── templates/cart.html          <- หน้าตะกร้าสินค้า
│   ├── templates/checkout.html      <- หน้ายืนยันการสั่งซื้อ
│   ├── templates/orders.html        <- หน้าประวัติคำสั่งซื้อของลูกค้า
│   ├── templates/order_detail.html  <- หน้ารายละเอียดคำสั่งซื้อ และฟอร์มแนบสลิป
│   ├── templates/login.html         <- หน้าเข้าสู่ระบบ พร้อมปุ่มดูรหัสผ่าน
│   ├── templates/register.html      <- หน้าสมัครสมาชิก พร้อมปุ่มดูรหัสผ่าน
│   └── templates/admin/
│       ├── nav.html                 <- แถบเมนูนำทางของแอดมิน (Admin Nav Bar)
│       ├── dashboard.html           <- แดชบอร์ดสรุปสถิติ ยอดขาย สต็อกเตือน
│       ├── products.html            <- ตารางจัดการสินค้า และปรับสต็อกรวดเร็ว
│       ├── product_form.html        <- แบบฟอร์มเพิ่ม/แก้ไขรถ (ล็อก CC <= 160)
│       ├── orders.html              <- รายการคำสั่งซื้อทั้งหมด พร้อมแท็บคลังประวัติ
│       ├── order_detail.html        <- จัดการคำสั่งซื้อ และเปลี่ยนสถานะ
│       ├── payments.html            <- ตรวจสอบสลิป อนุมัติ/ปฏิเสธยอดเงิน
│       └── reports.html             <- รายงานยอดขาย และมูลค่าสินค้าคงคลัง
│
└── [4. โฟลเดอร์ไฟล์สถิต มีเดีย และรูปภาพทั้งหมด - static]
    ├── static/css/style.css         <- สไตล์ชีตหลัก (ดีไซน์ Dark Cinematic / Red White)
    ├── static/fonts/tahoma.ttf      <- ฟอนต์ภาษาไทย Tahoma สำหรับสร้างใบเสร็จ PDF
    ├── static/fonts/tahomabd.ttf    <- ฟอนต์ภาษาไทย Tahoma ตัวหนา
    ├── static/images/               <- รูปภาพเวกเตอร์สำรอง (SVG) และ Placeholder
    ├── static/รูปภาพ/               <- ศูนย์รวมภาพถ่ายต้นฉบับจริง (รถ 20 รุ่น, แบนเนอร์, โลโก้, พื้นหลัง)
    └── static/ไฟล์ที่ผู้ใช้อัปโหลด/     <- โฟลเดอร์เก็บไฟล์ที่ผู้ใช้อัปโหลด (slips/ และ products/)
